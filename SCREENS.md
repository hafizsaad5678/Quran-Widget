# App Screens Overview

## 1. Home Screen (Main)
- **Beautiful daily ayah display** with today's verse
- **Dark/Light theme toggle** in header
- **Test notification button** (bell icon)
- **Two navigation buttons:**
  - Islamic Quotes - Browse inspirational quotes
  - Browse Ayat - Browse all 50 ayat

## 2. Islamic Quotes Screen
- **6 beautiful Islamic quotes** with authors
- **Quote cards** with elegant styling
- **Dark/Light theme support**
- **Back button** to return to home
- **Scrollable list** of quotes

## 3. Browse Ayat Screen
- **Select and view any of the 50 ayat**
- **Large display** of selected ayah
- **Arabic text** with translation
- **Surah name and ayah number**
- **Scrollable list** of all ayat
- **Tap to select** any ayah to view
- **Dark/Light theme support**

## Features

✅ **Beautiful UI**
- Clean, minimal design
- Light and dark themes
- Smooth navigation
- Professional styling

✅ **Offline-First**
- All data stored locally
- No internet required
- 50 ayat + 6 quotes

✅ **Notifications**
- Test button on home screen
- 12 daily notifications (every 2 hours)
- Same ayah in app and notifications

✅ **Navigation**
- Stack-based navigation
- Smooth transitions
- Back buttons on all screens

## Setup

```bash
cd quran-daily-ayah
npm install
npm start
```

## File Structure

```
src/screens/
├── HomeScreen.js      # Main screen with daily ayah
├── QuotesScreen.js    # Islamic quotes
└── AyahScreen.js      # Browse all ayat
```

## Styling

- **Light Theme:** White background, gold accents
- **Dark Theme:** Dark background, bright gold accents
- **Consistent:** All screens use same theme system
- **Responsive:** Works on all screen sizes
